## Task: Add Order Management to ASP.NET Core API

You are adding ORDER functionality to an existing ASP.NET Core 9 Web API that already has USER management.

## Requirements
1. Create OrderItem record with ProductId (string), Quantity (int > 0), UnitPrice (decimal > 0)
2. Create CreateOrderRequest with Items (List<OrderItem>, [MinLength(1)]) and Notes (string?, optional)
3. Create OrderResponse with Id, Items, TotalAmount, CreatedAt, Status
4. Create IOrderService interface and OrderService implementation
5. Add POST /api/v1/orders endpoint in OrdersController
6. Calculate TotalAmount as sum of (Quantity * UnitPrice) for all items
7. Use [FromBody] and model validation
8. Use constructor injection for IOrderService
9. Return 201 Created on success with created order
10. Return 400 BadRequest if validation fails
11. Register OrderService in DI container in Program.cs
12. Add xUnit tests for: (a) valid order creation, (b) empty items validation
